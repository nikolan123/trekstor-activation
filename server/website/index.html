TrekStor tablet activation

After the company that made this tablet went bankrupt, this tablet's activation servers were shut down too. I got my hands on one of the tablets affected and that annoyed me. So I decided to rebuild the server so all 100K+ units sold work again.

This service has served 0 successful activation requests.
